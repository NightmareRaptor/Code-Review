LESSON 01 · FOUNDATION

Variables & data types

A variable is a named place to store a value. A type tells Java what kind of value belongs there.

What it looks like

int age = 16;
double price = 4.99;
boolean isReady = true;
String name = "Alex";

int stores whole numbers. double stores decimal numbers. boolean stores true or false. String stores text.

Declaration and initialization

Declaration creates a variable by giving it a type and a name. Initialization gives it its first value. Java can do both in one statement, like int score = 90;

Common mistake

int score = 9.5; // Error: int cannot store this decimal

Use double score = 9.5; when you need to keep the decimal part.

Remember: Java is strict about types. The variable's type is like a container label.
MEMORY TRICK

Variables are labelled containers. The label tells you what kind of thing belongs inside.

QUICK CHECK

Which type would you use for a decimal such as 2.75?

LESSON 02 · FOUNDATION

Scanner & input

Input makes a program interactive. Output lets it communicate with the user.

A basic Scanner program

import java.util.Scanner;

Scanner input = new Scanner(System.in);
System.out.print("Your name: ");
String name = input.nextLine();
System.out.println("Hello, " + name);

Common input methods

  • nextInt() reads a whole number.
  • nextDouble() reads a decimal number.
  • next() reads one token, usually one word.
  • nextLine() reads a whole line of text.

Order matters

Import Scanner → create the Scanner → ask a question → read the answer → use the answer.

Remember: If Java says it cannot find Scanner, check that you have import java.util.Scanner; at the top.
MEMORY TRICK

Output is the speaker. Scanner is the microphone.

WATCH OUT

nextInt() reads a number, not a line of text.

LESSON 03 · CORE

Operators

Operators calculate values, compare things, and combine true-or-false conditions.

Arithmetic and comparison

int total = 8 + 3;       // 11
int remainder = 8 % 3;   // 2
boolean bigger = 8 > 3;  // true
boolean same = 8 == 3;  // false

Logical operators

  • && means AND — both conditions must be true.
  • || means OR — at least one condition must be true.
  • ! means NOT — reverses true and false.

Common exam trap

= assigns a value. == compares two values. The modulo operator % gives the remainder after division.

Example: 10 % 3 is 1, because 3 goes into 10 three times with 1 left over.
MEMORY TRICK

One equals assigns. Two equals asks if they are equal.

QUICK CHECK

What is the value of 17 % 5?

LESSON 04 · CORE

If / else decisions

Conditions let a program choose what to do based on the values it receives.

If, else-if, else

if (mark >= 80) {
    System.out.println("Great work!");
} else if (mark >= 50) {
    System.out.println("Pass");
} else {
    System.out.println("Try again");
}

Java checks from top to bottom and runs the first matching branch. Put the most specific or highest threshold first when that is what your logic needs.

Nested if

A nested if is an if statement inside another if statement. It is useful when a second decision only matters after the first condition passes.

Switch

Use switch when comparing one value against several specific cases, such as a menu option or day number.

Analogy: Imagine checkpoints. Once one condition sends you down a path, the other branches are skipped.
COMMON MISTAKE

Use == to compare primitive values. A condition must evaluate to a boolean.

LESSON 05 · CORE

Loops

Loops repeat instructions so you do not have to write the same code again and again.

For loop

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

The three parts are initialization (int i = 1), condition (i <= 5), and update (i++).

While loop

int count = 1;
while (count <= 3) {
    System.out.println("Go!");
    count++;
}

A while loop checks its condition before each run. Make sure something can eventually make the condition false, or the loop may never stop.

Analogy: A loop is a playlist on repeat. The condition decides when playback stops.
DEBUGGING TIP

If a loop runs too long, inspect the condition and the variable that should change.

REMEMBER

i++ increases i by one.

LESSON 06 · PRACTICE

Strings & methods

Strings store text. Methods help you inspect or compare the text you have stored.

Useful String methods

String word = "Java";
System.out.println(word.length());        // 4
System.out.println(word.charAt(0));       // J
System.out.println(word.equals("Java")); // true

Indexes start at zero

The first character of "Java" is at index 0, the second at index 1, and so on. Asking for an index outside the valid range can cause a runtime error.

Comparing Strings

Use equals() to compare String contents. The == operator is not the right way to test whether two Strings contain the same text.

Analogy: A String is a row of numbered lockers. The first locker is numbered 0, not 1.
EXAM TRAP

length() counts characters. charAt(index) gets one character.

REMEMBER

String begins with a capital S.

LESSON 07 · PRACTICE

Errors & debugging

When code does not work, identify the kind of error and narrow down the cause.

Three common error types

  • Syntax: Java rules were broken, so the code cannot compile.
  • Runtime: Something goes wrong while the program is running.
  • Logic: The program runs, but the result is incorrect.

Try / catch

try {
    int number = Integer.parseInt("hello");
    System.out.println(number);
} catch (NumberFormatException e) {
    System.out.println("Enter a whole number.");
}

The try block contains code that might throw an exception. The catch block handles a matching exception.

Logic error analogy: You follow a recipe, but accidentally use salt instead of sugar. The steps run; the result is wrong.

Debugging checklist

  • Read the error message.
  • Find the line where it happened.
  • Check variable values and conditions.
  • Change one thing at a time, then run again.
DEBUG METHOD

Reproduce → isolate → fix → retest. Avoid changing many things at once.

LESSON 08 · PUT IT TOGETHER

One complete program

Combine input, variables, validation, decisions, and output into a single working program.

Mark checker

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter a mark: ");
        int mark = input.nextInt();

        if (mark < 0 || mark > 100) {
            System.out.println("Invalid mark");
        } else if (mark >= 50) {
            System.out.println("Pass!");
        } else {
            System.out.println("Keep practising");
        }
    }
}

How to plan a program

  • Inputs: what does the user provide?
  • Variables: what values do you need to store?
  • Rules: what conditions or calculations are required?
  • Output: what should the user see?
Good habit: Test normal values and edge cases, such as 0, 50, 100, and invalid values.
